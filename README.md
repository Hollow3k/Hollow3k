# Hey, I'm Angad

Usually somewhere between "that sounds simple" and finding out why it isn't.

## Selected work

### Higenbot

A game idea goes in. A playable browser game comes out.

Four agents handle creative direction, game design, programming and QA. They generate TypeScript and HTML5 Canvas code, check the build, and send failures through a retry loop. Once it runs, you can keep changing the game through chat.

[Code](https://github.com/Hollow3k/higenbot) · [Try it](https://higenbot.vercel.app)

### Shay

Design the database before getting buried in queries.

Draw tables and relationships on a React Flow canvas, ask AI to draft or change the schema, and inspect the result before exporting SQL. Supports PostgreSQL, MySQL and SQLite, with debounced autosave while you work.

[Code](https://github.com/Hollow3k/shay) · [Try it](https://shay-five.vercel.app)

### PitchPerfect

Practice the part of a pitch you can't prepare in slides: the questions.

Live voice sessions with five AI investor personas, powered by ElevenLabs WebRTC. After the conversation, transcript-based analysis scores the pitch across four dimensions and gives coaching feedback and investor-fit assessments.

[Code](https://github.com/Hollow3k/pitch-perfect) · [Try it](https://pitchperfect.angad.social)

### Sentinel

A fraud score should come with a reason.

An XGBoost + FastAPI credit-card fraud scoring API. SHAP explanations show what influenced a prediction, and a React dashboard lets analysts review flagged transactions.

[Code](https://github.com/Hollow3k/sentinel)
